# Clean-room rules

These rules are binding for every contributor, human or AI agent, on every PR.

1. Do **not** visit, fetch, scrape or screenshot `supereasytimer.com`, its web timer, or its App Store page while working on this repo. The issues and `docs/PRODUCT_SPEC.md` are the only product reference.
2. Do **not** download, open, decompile, disassemble, `class-dump`, `strings`, or inspect the bundle/resources of the original Mac app.
3. Do **not** copy UI text, marketing copy, help text, colors-by-name lists, layouts, icons, images, sounds or fonts from it.
4. Do **not** use the names "Super Easy Timer", "SuperEasyTimer", "Super Easy Apps" or anything confusingly similar in code identifiers, bundle IDs, product name, icon, UI, release names or store listings.
5. All visual design follows the specs in #8 and #13. All sounds are generated by our script (#10) or referenced at runtime from macOS system sounds (never copied into the repo).
6. Third-party code: permissive licenses only, added to `THIRD_PARTY_NOTICES.md` in the same PR. No copy-pasting snippets without a compatible license and attribution.
7. AI agents follow the same rules; when unsure, stop and ask in the issue.
8. Every new asset (image, sound, icon) gets a row in the Provenance log: file, how it was created (script/command), author, date, license.
