# CornerTimer — product spec

> Versioned copy of sections 1–3 of epic #1. Future spec changes happen via PR.

## 1. What we're building

**CornerTimer** (working name — see #2) is a small, free, open-source **macOS menu-bar countdown timer** for personal use. Its defining traits:

1. **One text box does everything.** Type `25`, `1h 30m`, `90s`, `5pm` or `+5m` and press Return.
2. **A floating mini-window** that stays on top of everything — including full-screen Keynote/PowerPoint/Zoom — parks itself in a screen corner, and never steals keyboard focus from the app you're using.
3. **Live countdown in the menu bar.**
4. **Clear "time's up"**: sound, notification and a visual flash; optional count-up ("overtime") after zero.
5. **Global keyboard shortcuts** to control it from any app.
6. **Easy install** on the owner's Mac: `make install` from source, or download a release `.zip`/`.dmg`.

This project is a **clean-room, independent implementation** of a common product idea (a floating countdown timer). It is inspired by the general category of apps such as "Super Easy Timer", but it is **not affiliated with, endorsed by, or derived from** that product, and must not copy its code, assets, text, name or look. See #2 — those rules are binding for every PR.

## 2. Platform & tech decisions (fixed for MVP)

| Topic | Decision |
|---|---|
| OS target | macOS **14 Sonoma** or later (`LSMinimumSystemVersion 14.0`), Apple Silicon + Intel (universal binary) |
| Language/UI | Swift 5.10+ (Xcode 16+), **SwiftUI for views, AppKit for windowing/menu bar** (`NSPanel`, `NSStatusItem`) |
| Build system | **Swift Package Manager only** — no `.xcodeproj` checked in (avoids merge conflicts between agents). A shell script assembles the `.app` bundle. |
| Modules | `TimerCore` (pure Swift + Foundation, **no AppKit/SwiftUI/Combine**, builds & tests on Linux) and `CornerTimerApp` (macOS executable) |
| App type | Menu-bar agent app (`LSUIElement = YES`, no Dock icon) |
| Bundle ID | `com.ahmosguc.cornertimer` |
| Dependencies | Only [`sindresorhus/KeyboardShortcuts`](https://github.com/sindresorhus/KeyboardShortcuts) (MIT) for global hotkeys. Anything else needs owner approval. |
| Distribution | Ad-hoc code signing (no paid Apple Developer account needed). Developer ID signing + notarization is post-MVP (#18). |
| License | MIT (see #2) |

## 3. MVP feature spec (summary — details live in each issue)

| # | Area | Summary |
|---|---|---|
| #5 | Input parser | Durations, clock times, `+/-` adjustments; friendly errors |
| #6 | Timer engine | idle → running ⇄ paused → finished/overtime; wall-clock accurate; survives sleep |
| #7 | Floating panel | Always on top, all Spaces, over full-screen apps, non-activating, corner snapping, multi-display |
| #8 | Timer view & themes | Original visual design, 4 original themes, size & opacity, hover-reveal controls, progress bar |
| #9 | Menu bar | Live remaining time, presets, controls menu |
| #10 | Time's up | Original chime generated by our own script (repeat N), notification with actions, flash, Reduce Motion support |
| #11 | Global shortcuts | Show/focus, start/pause, reset, +1 min — user-configurable |
| #12 | Settings & persistence | Settings window, UserDefaults, launch at login |
| #13 | App icon | Original icon drawn by a script; provenance documented |
| #14 | Packaging & local install | `.app` assembly, ad-hoc signing, `make install/uninstall`, zip + dmg |
| #15 | Release pipeline | Tag → GitHub Release with zip/dmg/sha256 |
| #16 | Docs & screenshots | README, install guide (incl. Gatekeeper), screenshots of **our** app only |
| #17 | End-to-end QA | Manual acceptance on a real Mac |

### Explicit non-goals for MVP (tracked in #18)
Pomodoro/tabata, stopwatch, clock mode, repeating timers, full-screen big-digits mode, multiple simultaneous timers, Liquid Glass material, Windows/iOS, Homebrew cask, Developer ID notarization, auto-update, localization.
