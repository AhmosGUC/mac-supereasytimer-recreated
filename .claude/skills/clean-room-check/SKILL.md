# Clean-room check

CornerTimer is an independent implementation of a common product idea. Copyright protects code, art, text and sounds, not ideas or features — so the risk is in *what we copy*, not *what we build*. This check enforces `docs/CLEAN_ROOM.md`. If anything fails, fix it before opening the PR.

## Automated checks (run from repo root)

```bash
base=$(git merge-base HEAD origin/master)

# 1. Forbidden product names (same rule as the CI lint job)
git grep -nIi -E 'super ?easy ?(timer|apps)' -- . \
  ':!docs/CLEAN_ROOM.md' ':!docs/PRODUCT_SPEC.md' ':!README.md' ':!.github' \
  | grep -v 'mac-supereasytimer-recreated' || echo "OK: no forbidden names"

# 2. TimerCore stays platform-independent
git grep -nE '^\s*(@testable\s+)?import\s+(AppKit|SwiftUI|Combine|UIKit|os)\b' -- Sources/TimerCore \
  || echo "OK: TimerCore imports clean"

# 3. Hardcoded product name / bundle ID outside the allowed places
git grep -nE 'CornerTimer|com\.ahmosguc\.cornertimer' -- Sources \
  ':!Sources/CornerTimerApp/AppConstants.swift' | grep -vE '^\S+:\s*//' | grep -E '"' \
  && echo "WARN: string literal with product name/ID — use AppConstants" || echo "OK"

# 4. New binary/asset files in this branch
git diff --name-only --diff-filter=A "$base"...HEAD \
  | grep -Ei '\.(png|jpe?g|gif|svg|pdf|icns|ico|wav|aiff?|mp3|m4a|caf|ttf|otf|woff2?)$' || echo "OK: no new assets"

# 5. Dependency changes
git diff "$base"...HEAD -- Package.swift Package.resolved | grep -E '^\+.*(url|identity|location)' || echo "OK: no dependency changes"
```

## Manual checks

For every **new asset** from check 4:
- [ ] It was created by us — generated by a script in `scripts/`, rendered by `make previews`, or a screenshot of **CornerTimer itself** taken by the owner.
- [ ] It has a row in the Provenance log in `docs/CLEAN_ROOM.md`: `File | Created by (tool/command) | Author | Date | License`.
- [ ] It is not a screenshot, icon, sound or image of any other app or website, and doesn't use SF Symbols inside the **app icon** (SF Symbols are fine inside the UI).

For every **dependency change** from check 5:
- [ ] License is MIT, BSD or Apache-2.0 (check the dependency's LICENSE file).
- [ ] It's listed in `THIRD_PARTY_NOTICES.md` with its copyright line, and the version matches `Package.resolved`.
- [ ] The owner approved it (only `KeyboardShortcuts` is pre-approved).

For **code and text**:
- [ ] No code, UI strings, help text or marketing copy came from another product, its website, or its web timer. No decompiling or inspecting another app's bundle.
- [ ] Snippets from Stack Overflow, blogs or other repos are either rewritten in your own words or carry a compatible license plus attribution.
- [ ] User-visible text and docs are written in our own words. Branding is "CornerTimer" only.
- [ ] The only allowed mention of the other product is the README non-affiliation notice from #2 (exact wording). The in-app About text names no other product.

## Output
Paste a short summary into the PR description under "Clean-room checklist": the result of each automated check, plus the ticked manual items. If something can't be ticked honestly, say so and ask the owner instead of ticking it.
